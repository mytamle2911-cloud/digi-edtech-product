# Product concept, scope & UX

## Value proposition
Learn practical digital and AI skills in short, interactive sessions — using a localized, mobile-first experience.

## Documented MVP activities
- Gamified quiz activities.
- Short instructional materials delivered through multiple formats.
- Participant testing and observed product use.

## Proposed future capabilities
- Structured learning paths and ongoing gamification.
- Better onboarding.
- Student progress visibility and parent-facing reporting.
- Expanded learning content and school partnership features.

**Scope rule:** A planned feature is not labeled as shipped. The supplied proposal contains both concept screens and future roadmap items.

## Product decisions to explore
| Need | Candidate enhancement | How to evaluate |
| --- | --- | --- |
| First-time learner confusion | Guided onboarding | First-module start/completion |
| Drop-off after initial excitement | Short daily tasks | Repeat sessions, D7/D14 retention |
| Unclear sense of improvement | Skills-based progress summaries | Perceived learning value |
| Parent doubts about practical relevance | Explain the 'why' behind each module | Parent usefulness feedback |

Candidate metrics are evaluation proposals, not demonstrated results for the confirmed 52/15 sample.
